# Virtual Healthcare Data Analytics

## Project Overview

This project explores how healthcare data analytics and machine learning can support virtual healthcare operations.

The case study focuses on predicting 30-day hospital readmission risk among patients with diabetes using publicly available healthcare data.

## Dataset

The proposed case study uses the:

**Diabetes 130-US Hospitals for Years 1999-2008**

Source: UCI Machine Learning Repository
